Connect Discord

The bot token that lets Requestarr actually run in your server.

Where do I get a bot token?
  1. Go to the Discord Developer Portal → New Application.
  2. Bot tab → Reset Token → copy it (you won't see it again).
  3. OAuth2 → URL Generator: check bot and applications.commands, pick the permissions it needs, then open the generated URL to invite it to your server.
  4. Enable Developer Mode in Discord (User Settings → Advanced), then right-click your server icon → Copy Server ID for the guild ID above.
